## 🌍 About the Project

An interactive, immersive web experience built for the **NASA International Space Apps Challenge 2026**. This project brings the history and wonder of space exploration to life through stunning 3D visuals, real-time data, and engaging storytelling.

---

## ✨ Features

| Feature | Description |
|---|---|
| 🪐 **3D Solar System** | Interactive real-time 3D solar system built with Three.js |
| 🛸 **DSN Live Tracker** | Real-time Deep Space Network signal tracking |
| 📖 **Mission Storyline** | Immersive narrative journey through space missions |
| 🏅 **Cosmic Passport** | Earn your space explorer passport with quizzes |
| 🎖️ **Relic Dossier** | Explore historical space mission relics |
| ⏱️ **Timeline Slider** | Interactive space exploration timeline |
| 🎨 **3D Craft Models** | Beautifully rendered spacecraft 3D models |
| 🔊 **Audio Effects** | Immersive space audio experience |

---

## 🛠️ Tech Stack

- **Frontend**: Vanilla JavaScript (ES Modules)
- **3D Rendering**: [Three.js](https://threejs.org/) v0.186
- **Build Tool**: [Vite](https://vitejs.dev/) v8.3
- **Animations**: Canvas Confetti
- **Design**: Custom CSS with glassmorphism & dark mode

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/Araf1011/Nasa_SpaceApp_Challenge2026.git

# Navigate to the project
cd Nasa_SpaceApp_Challenge2026

# Install dependencies
npm install

# Start the dev server
npm run dev
```

Then open your browser at `http://localhost:5173` 🚀
